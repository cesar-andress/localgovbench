## One-sentence description

LocalGovBench is a reproducible research repository for studying disclosure affordances and planned record-level realization in public AI and algorithm registers using Disclosure Functions v1.

## Short repository description (GitHub / Zenodo blurb)

Research software for schema disclosure affordance in public AI and algorithm registers (Disclosure Functions v1). Framework transition from historical v0.1.0; not a completed empirical-results release.

## Long repository description

LocalGovBench provides reproducible artefacts for analysing what official public AI / algorithm register **schemas** can host (schema disclosure affordance) under **Disclosure Functions v1**, and for preparing applicability-aware **human schema coding**, documentary linkage, and future **record-level realization** and affordance–realization gap analysis. The active path does not produce jurisdiction rankings, readiness or maturity scores, shortfall scores, compliance scores, or composite governance indices.

## Scope statement

**In scope for the active framework**

- Disclosure Functions v1 catalogue and anti-overcredit rules  
- Observed schema inventory from a locked 7,434-record multi-source corpus  
- Field normalization, candidate mapping, applicability, and realization specifications  
- Human schema-coding system (codebook, templates, validation, double-coding and adjudication protocols)  
- A 33-unit pilot coding manifest  
- Reproducible build scripts and tests for the specification and coding layers  

**Out of scope as completed claims in v0.2.0**

- Completed human pilot coding outcomes  
- Reported IRR statistics  
- Adjudicated full-study schema-support results  
- Record realization rate tables  
- Affordance–realization gap results and final figures  
- A finished companion journal manuscript  

## Non-claims statement

LocalGovBench v0.2.0 does **not** claim to measure governance readiness, governance maturity, sovereign LLM deployment readiness, compliance, or municipal ranking. Historical v0.1.0 materials that used those constructs remain archived for provenance only.

## Transition note from v0.1.0

v0.1.0 represented the original Governance Readiness Benchmark design. It is retained as a historical snapshot (Zenodo DOI `10.5281/zenodo.20543779`) but is not the active analytical framework. Do not treat GRB readiness outputs as current LocalGovBench results.
