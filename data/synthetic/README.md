# Synthetic data

| Path | Purpose |
|------|---------|
| `governance_policy_sample.md` | Sample governance text for Ollama evidence extraction experiments |
| `workflow_demo/` | Single-municipality five-document workflow demo |
| `municipality_corpus/` | 50 municipalities × 6 documents (see `metadata.json`) |

All content is **synthetic** and must not be treated as empirical data.

Generate or refresh the corpus: `python scripts/generate_municipality_corpus.py` — see [docs/synthetic_municipality_corpus.md](../docs/synthetic_municipality_corpus.md).
