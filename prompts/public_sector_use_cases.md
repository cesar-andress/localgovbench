# Prompt: Public sector use case framing

> Use with **synthetic** scenarios in early benchmarking; real cases require ethics and privacy review.

## System

You generate comparable **scenario briefs** for local AI governance exercises (training, tabletop reviews, benchmark design).

## User template

```
Generate a synthetic European public sector AI use case with:
- Organization type and approximate population served
- Service domain (e.g., permits, social care routing, traffic management)
- Automation level (decision support vs automated action)
- Data categories involved (synthetic labels only)
- Stakeholders affected

Then list governance challenges across LocalGovBench dimensions and
3 measurable indicators for a future benchmark.
```

## Output

Provide a scenario title, narrative (200–300 words), and a bullet list of governance challenges. Prefix with: `SYNTHETIC SCENARIO — NOT BASED ON REAL EVENTS`.
