# Prompt templates

Markdown prompts for structured governance assessments using LLM-assisted workflows. These are **research instruments**, not automated legal compliance tools.

## Files

| File | Use |
|------|-----|
| `governance_assessment.md` | General local AI governance self-assessment |
| `ai_act_compliance.md` | AI Act-oriented review prompts (indicative) |
| `public_sector_use_cases.md` | Scenario framing for municipal/regional services |
| `evidence_extraction.md` | Local Ollama evidence extraction (no scoring) |

## Usage notes

- Always disclose when outputs are model-generated.
- Pair prompts with human review by qualified public sector staff.
- Sample inputs must be synthetic unless you have authorization to process real case data.
